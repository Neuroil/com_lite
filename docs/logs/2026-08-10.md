## 1. fan-out 落地回顾（commit 55f90e9，2026-08-08）

### 1.1 背景

「跨 fd 转发」epic 的收尾子项（TODO.md 第 1 条）：目标 uid 的 fd 集合解析与多 fd 分发，
协调层职责（`docs/architecture.md` §2.2）。前置全部就绪：
- `user.h` 的 `fds_` 向量 + `vec()`（2026-08-06，commit 2e315b2）；
- `pending_close_` 排除 + 失败归因「杀目标」（2026-08-06）；
- `EPOLLOUT` 武装（2026-08-07）。

### 1.2 query_all 双层 API

- `UsersGroup::query_all(uid, const std::vector<int>*& fds)`（`users_group.h:174`）：
  uid 不存在时置 `fds = nullptr` 并返回 false；成功返回指向该用户 `fds_` 的只读向量指针。
  指针语义与单线程现状匹配，多线程化后需重审生命周期（见 §4.2）。
- `Controller::query_all`（`controller.cpp:111`）透传，作为协调层对外接口；
  `Controller::query`（单 fd 版本）保留，仍有调用方（登录成功后的 `query` 闭环等）。

### 1.3 request 分支多 fd 分发

`controller.cpp:73` `query_all` 查路由 → `:82-84` 对 `*fds` 循环
`out_queue.emplace_back(rmp, to_fd)`。要点：

- 目标在线 = `response(ok)` 已入队；不在线 = `response(fail)` + drop 日志
  （「peer not online」），发送方必须知情。
- 转发帧是 `rmp` 的按 fd 拷贝（每条 fd 一份），与既有「装配 → 入队」路径一致。
- 自发自收（发送方 fd 在目标集合内）**不做排除**：是否自收是 core 层的处置范畴
  （`to_fd == fd` 回落入站杀点），协调层只按集合全量分发。

### 1.4 回执投递范围（实现默认，未显式拍板）

`response` 帧只回**入站 fd**（发送方当前设备），发送方其它设备不收。这是落地时的
实现默认，8/7 日志 §8.1 遗留的「发送方回执投递范围」决策点尚未显式拍板，见 §4.1。

## 6. 附属项目 com_lite_client：operation.h Windows 移植（本次）

> com_lite_client 是 com_lite 的附属客户端验证项目（独立目录 `C:\Users\Neuroil\code\com_lite_client`，
> 未纳入 git，工作区直改）。本次将其 `operation.h` 从 POSIX socket 写法移植到 Winsock；
> 逻辑语义一对一平移，无行为变更。

### 6.1 背景

`main.cpp` 已是 Windows 写法（`WSAStartup` / `SOCKET` / `closesocket`，`WinSock2.h` + `ws2tcpip.h`），
但 `operation.h` 残留 POSIX 写法：`errno` / `EAGAIN` / `EWOULDBLOCK` / `EINTR` 错误分支、
`timeval` 型 `SO_RCVTIMEO`、`int fd` 参数（x64 下 `SOCKET` 为 64 位，`int` 会截断）。
这些在 Windows 上不生效：Winsock 用 `WSAGetLastError()` 报错，超时/无数据表现为
`WSAETIMEDOUT` / `WSAEWOULDBLOCK`，`SO_RCVTIMEO` 取值是 DWORD 毫秒而非 `timeval`。

### 6.2 改动清单（`operation.h`）

1. **include 顺序**（`:13-23`）：`WinSock2.h` 之后补 `<windows.h>`（避免冲突拉入 winsock.h）、
   `NOMINMAX` 保护（防 `min`/`max` 宏污染）、补 `<cstring>`；`#pragma comment(lib,"ws2_32.lib")`
   加 `_MSC_VER` 保护（MSVC 下自动链接，MinGW 下不报无效 pragma）。
2. **新增 `wsa_last_error_string()`**（`:93`）：`FormatMessageA` 格式化 `WSAGetLastError()`，
   替代 POSIX `strerror(errno)`。
3. **`set_recv_timeout`**（`:111`）：`timeval` → `DWORD` 毫秒（Windows `SO_RCVTIMEO` 语义）。
4. **错误分支**（`:205` `recv_frames`、`:246` `recv_expect_close`、`:287` `pump_inbound`）：
   `errno`/`EAGAIN`/`EWOULDBLOCK`/`EINTR` → `WSAGetLastError()` + `WSAETIMEDOUT`/
   `WSAEWOULDBLOCK`/`WSAEINTR`；`ECONNRESET` 注释同步为 `WSAECONNRESET`。
5. **签名**：三处 `int fd` → `SOCKET fd`（同上锚点），避免 x64 句柄截断。

### 6.3 验证

- `main.cpp` 侧零改动，`login_as` / `send_all` / `recv_frames` 调用点全部兼容。
